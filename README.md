# Cutest Picture — make.fun entry

A cream kitten with big sapphire-blue eyes, a gentle blep, a daisy crown and
a mint scarf, hugging a tiny chick that wears a matching daisy.

The program (`main.ts`, Node 22, standard library only) copies `entry.png`
to `/output/entry.png`. Deterministic: two runs write identical bytes.
